      使い方

      データをプロットし、線形近似・非線形近似 (カスタム式)・Savitzky-Golay 平滑化を行います。設定を変えるとグラフはすぐに更新されます。計算はすべてこの端末の中で行われ、データが外部に送られることはありません。

      データを入れる

      • ＋ 新規 … 空のデータセットを作り、表に入力します。
      • 貼り付け / テキストで編集 … Excel などからコピーした表 (X, Y, Y誤差, X誤差) をまとめて入力できます。
      • 取り込み … CSV / TSV / TXT / Excel (xlsx) を読み込みます。ヘッダ行と誤差列は自動判定します。
      • 数式 … np.sin(x) のような数式からデータを作ります。

      近似

      • 非線形 (カスタム) は a * exp(-b * x) + c のように書きます。x 以外の名前 (a, b, c …) がフィットパラメータになります。
      • Y誤差を入れたデータは「Y 誤差で重み付けする」で重み付きフィットができます。

      保存と書き出し

      • プロジェクトを保存 … .gproj ファイルとして保存します。PC 版 (Windows) と同じ形式なので、PC と スマホ の間でそのまま開けます。
      • 画像を書き出し … PNG / PDF / SVG / EPS / TIFF。図は「グラフ設定」の幅 × 高さ (cm) どおりの大きさになります。
      • 作業中のプロジェクトはこのブラウザに自動で保存され、次に開いたときに復元されます。

      ホーム画面に追加

      iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、アプリのように起動できます。一度読み込めばオフラインでも使えます (Excel の取り込みは初回のみ通信が必要)。
