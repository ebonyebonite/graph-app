        使い方

        データをプロットし、近似 (線形・多項式・指数・非線形など) と統計の計算を行います。設定を変えるとグラフはすぐに更新されます。

        データの扱い

        • 計算はすべてこの端末の中で行われ、入力したデータやファイルが外部に送られることはありません。
        • 起動時に、ブラウザで Python を動かすための部品を jsDelivr (CDN) から、Excel 読み込み用の部品を PyPI から取得します (データは送りません)。
        • 作業中の内容はこのブラウザ内に保存されます。共用の端末で使ったときは、メニューの「このブラウザの保存データを消去」で消してください。

        データを入れる

        • ＋ 新規 … 空のデータセットを作り、表に入力します。
        • 貼り付け / テキストで編集 … Excel などからコピーした表 (X, Y, Y誤差, X誤差) をまとめて入力できます。
        • 取り込み … CSV / TSV / TXT / Excel (xlsx) を読み込みます。ヘッダ行と誤差列は自動判定します。
        • 数式 … np.sin(x) のような数式からデータを作ります。

        複数のグラフ

        • 画面上部のタブで、いくつかのグラフを同時に開いて切り替えられます。＋ で新しいグラフを追加します (グラフ設定は今のグラフから引き継ぎます)。
        • 選択中のタブをもう一度押すと名前を変更できます。名前は保存・書き出しのファイル名になります。タブはドラッグで並べ替えられます。
        • データ・グラフ設定・「元に戻す」の履歴はグラフごとに別々です。保存 (.gproj) と書き出しは選択中のグラフが対象です。
        • プロジェクトを開くと新しいタブで開きます (複数のファイルを選ぶとそれぞれ別のタブになります)。
        • 閉じたグラフは、メニューの「閉じたグラフを復元」で戻せます (新しい順に 5 つまで)。
        • データ表の「別のグラフへ」で、データセットをほかのタブにコピーできます。

        データの入力と加工

        • Excel などでコピーした範囲は、データ表のセルを選んでそのまま貼り付けられます (選んだセルが左上になります)。
        • 加工 … 式による変換 (ln y、1/x など。誤差棒も換算します)、並べ替え、同じ X の点の平均、微分、積分、規格化、範囲の切り出し、X と Y の入れ替え。
        • CSV 保存 … データセットを CSV ファイルにします。

        近似

        • 線形・比例・多項式・指数・累乗・対数・非線形 (カスタム)・Savitzky-Golay 平滑化が選べます。指数と累乗は対数に直さず、元のデータに対する最小二乗で求めます (Excel の近似曲線とは少し違うことがあります)。
        • 非線形 (カスタム) は a * exp(-b * x) + c のように書きます。x 以外の名前 (a, b, c …) がフィットパラメータになります。
        • テンプレート (指数減衰、ガウス関数、ミカエリス・メンテンなど) を選ぶと、式と初期値が入ります。うまく合わないときは初期値を実際の値に近づけてください。
        • 近似に使う X の範囲 … 直線になる部分だけを近似するときなどに指定します。
        • 区間の帯 … 近似線の信頼区間、または新しい測定値が入る予測区間を、線のまわりに薄い帯で描きます。
        • Y誤差を入れたデータは「Y 誤差で重み付けする」で重み付きフィットができます。

        統計

        • 結果 タブに、パラメータの標準誤差と信頼区間、R²、補正 R²、残差の標準偏差が出ます。値と誤差は、誤差の有効数字 2 桁の位にそろえて表示します。
        • 近似式で計算 … x から y を求めるほか、y から x を逆算できます (検量線から未知試料の濃度と不確かさを求めるときなど)。
        • 基本統計量 … 点数・平均・標準偏差 (n−1)・標準誤差・中央値・最小・最大、相関係数、面積 (台形則)。
        • 平均の比較 … 2 つのデータセットの平均の差を t 検定 (Welch / 対応あり) で調べます。
        • グラフ設定の「統計」で、信頼水準 (既定 95 %) と、残差 (測定値 − 近似値) のグラフの表示を選べます。
        • 信頼区間は、重みなしの近似では t 分布から求めます。Y 誤差で重み付けした近似では、誤差を既知の標準偏差とみなして正規分布から求め、当てはまりは χ²/自由度 (1 に近いほど誤差と合っている) で確かめます。

        保存と書き出し

        • プロジェクトを保存 … .gproj ファイルとして保存します。PC 版 (Windows) と同じ形式なので、PC と スマホ の間でそのまま開けます。
        • 画像を書き出し … PNG / PDF / SVG / EPS / TIFF。図は「グラフ設定」の幅 × 高さ (cm) どおりの大きさになります。
        • 作業中のグラフ (開いているタブすべて) はこのブラウザに自動で保存され、次に開いたときに復元されます。
        • プレビューにポインタを置く (スマホではタップする) と、その位置の座標が左下に出ます。
        • PC では Ctrl+S でプロジェクトを保存、Ctrl+Z / Ctrl+Y で元に戻す・やり直しができます。

        ホーム画面に追加

        iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」で、アプリのように起動できます。一度読み込めばオフラインでも使えます (Excel の取り込みは初回のみ通信が必要)。
